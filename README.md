# DSA-project-
# Online Exam Question Management System

## About the Project
The Online Exam Question Management System is a web-based project
developed to manage questions and conduct online examinations.

It provides a basic interface for students and teachers to access
examination-related features.

## Objectives
- To manage examination questions.
- To provide an online examination interface.
- To make question management easier.
- To display examination results.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- User login interface
- Student and teacher options
- Registration form
- Dashboard navigation
- Online examination interface
- Question bank interface

*Note: Some features are still under development.*

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the available features.
